# ssl-check

Bash-скрипт для проверки SSL/TLS-сертификатов ваших серверов. Для каждого сервера из списка он скачивает сертификат, проверяет срок действия, сверяет IP с DNS и убеждается, что сервер отвечает `HTTP 200`.

Интерфейс на русском: интерактивное меню, спиннер, цветные статусы и итоговая таблица.

```
● smart.example.com  203.0.113.10:443
  ⎿  Сертификат сохранён: certs/smart.example.com.pem
  ⎿  Издатель: R13
  ⎿  Действует до: 29.01.2027 — осталось 74 дн. ✓
  ⎿  Ответ сервера: HTTP 200 ✓

● Итоги
  Домен                         IP                До           Дней    HTTP    Статус
  smart.example.com             203.0.113.10      29.01.2027   74      200     ✓ OK
  old.example.com               203.0.113.10      28.05.2026   -171    200     ✗ Истёк

✻ Проверено: 2 · в порядке: 1 · предупреждений: 0 · ошибок: 1
```

## Возможности

- Скачивает сертификат с сервера по **заданному IP** (с SNI), а не по тому, что отдаёт DNS, и сохраняет его в `certs/<домен>.pem`.
- Проверяет **срок действия** и считает дни до окончания.
- Сверяет IP из списка с **DNS-записями** домена (A и AAAA).
- Проверяет, что сервер отвечает **HTTP 200**.
- Предупреждает, если сертификат выдан **не для этого домена**.
- Хранит список серверов в **отдельном текстовом файле** `servers.txt`; если IP у домена не задан, спрашивает его и сохраняет в файл.
- **Меню**: проверить все серверы, добавить сервер, удалить сервер, выйти.
- Режим `--check` без интерактива и с кодом возврата — для cron и CI.

## Требования

- `bash` 3.2 или новее (подойдёт стандартный bash в macOS)
- `openssl`
- `curl` (без него HTTP-проверка пропускается)
- `dig`, `dscacheutil` или `getent` — для запросов к DNS (хватит любого из них)

Проверялось на macOS. На Linux скрипт рассчитан работать (учитывает GNU `date`), но там отдельно не тестировался.

## Установка

```bash
git clone https://github.com/<ваш-аккаунт>/ssl-check.git
cd ssl-check
chmod +x ssl-check
```

## Использование

```bash
./ssl-check                  # интерактивное меню
./ssl-check --check          # сразу проверить все серверы и выйти
./ssl-check мой_список.txt   # использовать другой файл списка
./ssl-check --help           # справка
```

### Меню

```
● Что сделать?
  ⎿  1  Проверка всех серверов
  ⎿  2  Добавить сервер
  ⎿  3  Удалить сервер
  ⎿  4  Выйти
```

| Пункт | Что происходит |
|---|---|
| 1. Проверка всех серверов | Проходит по списку и выводит результат по каждому серверу и итоговую таблицу. |
| 2. Добавить сервер | Спрашивает домен, IP (Enter — взять из DNS, `s` — задать позже) и порт. Проверяет домен на корректность и на дубль. |
| 3. Удалить сервер | Показывает нумерованный список, просит номер и подтверждение. Комментарии в файле сохраняются. |
| 4. Выйти | Завершает работу. |

В любом диалоге Enter возвращает в меню.

## Список серверов

Файл `servers.txt` лежит рядом со скриптом. Если его нет, скрипт создаст его сам. Образец — `servers.example.txt`.

```text
# домен  IP-адрес  [порт]
example.com 93.184.216.34
api.example.com 203.0.113.10 8443
new.example.com
```

- Порт необязателен, по умолчанию 443.
- Если IP не указан (как у `new.example.com`), при проверке скрипт спросит его и допишет в строку.
- Строки, начинающиеся с `#`, и пустые строки игнорируются. Комментарий в конце строки тоже допустим.

> `servers.txt` добавлен в `.gitignore`, чтобы ваш рабочий список не попал в репозиторий.

## Что проверяется и как оцениваются результаты

| Проверка | Результат |
|---|---|
| Срок действия: осталось 15 дней и больше | ✓ OK |
| Срок действия: осталось меньше 15 дней | ⚠ Скоро истекает |
| Срок действия: истёк | ✗ Истёк |
| IP не совпадает с DNS-записями домена | ✗ Неправильный IP |
| IP записан некорректно | ✗ Неверный IP |
| Сервер не ответил или отказал в соединении | ✗ Таймаут / Ошибка |
| HTTP-ответ не 200 | ✗ HTTP *код* / Нет ответа HTTP |
| Сертификат выдан не для этого домена | ⚠ Чужой домен |
| IP не задан и пропущен пользователем | ⚠ Нет IP |

Порог предупреждения (`WARN_DAYS`) и таймаут (`TIMEOUT`, секунд) задаются в начале скрипта.

## Использование в cron и CI

В режиме `--check` скрипт не показывает меню. Цвета и спиннер автоматически отключаются, если вывод не в терминале. Если у домена не задан IP, запрос пропускается (нет ввода) и домен получает статус «Нет IP».

Код возврата: `0` — всё в порядке, `1` — есть предупреждения или ошибки.

```cron
# каждый день в 9:00
0 9 * * * /path/to/ssl-check --check >> /var/log/ssl-check.log 2>&1
```

## Особенности и ограничения

- **Редиректы не обрабатываются.** Домен, который отвечает `301`/`302`, получит ошибку, потому что ожидается именно `200`. Чтобы следовать редиректам, добавьте `-L` к вызову `curl` в скрипте.
- **CDN и балансировщики.** Если DNS отдаёт меняющийся набор IP, IP из списка может не оказаться среди текущих записей, и скрипт назовёт его неправильным.
- **HTTP-проверка идёт без проверки цепочки сертификата** (`curl -k`), чтобы код ответа был виден даже при просроченном сертификате. Срок и соответствие домену проверяются отдельно.
- Проверяется только корневой путь `/` по HTTPS.
